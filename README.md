# Need for Speed High Stakes Pocket PC (.z3d, .trk) importer/exporter
[![Blender](https://img.shields.io/badge/Blender-v5.2+-blue?logo=blender&logoColor=white)](https://www.blender.org/releases/5-2/)
[![License: GPL-3.0](https://img.shields.io/badge/License-GPLv3-blue.svg)](https://www.gnu.org/licenses/gpl-3.0)

[![ko-fi](https://ko-fi.com/img/githubbutton_sm.svg)](https://ko-fi.com/PolySoupList)

A Blender Add-on that enables importing and exporting vehicles and tracks as Need for Speed High Stakes Pocket PC (.z3d, .trk) files.

## Requirements
- [Blender 5.2 or newer](https://www.blender.org/releases/5-2/)

## Installation
Go to `Edit > Preferences > Addons > Install` and either select .zip file or the unzipped `import_nfshs_ppc_models.py` and `export_nfshs_ppc_models.py` files.

## Location
`File > Import > Need for Speed High Stakes Pocket PC (.z3d, .trk)`
|
`File > Export > Need for Speed High Stakes Pocket PC (.z3d, .trk)`
